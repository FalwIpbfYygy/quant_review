## 0. 为什么需要这份文件（第一性原理，不变）

亏损最常见、也最隐蔽的形态，不是"看错方向"，而是 **把"出现了看涨形态"直接当成"现在是做多行情"**。

形态（structure）是中性描述：吞没、锤子、突破、背离、旗形……本身不带方向。
方向（bias）由三件事决定：**当前处于哪个阶段 + 形态落在哪个位置 + 有没有确认信号**。

> 一句话：**形态中性，方向由"阶段背景 × 位置 × 动能 × 确认"四道闸给。**
> 这一条是整份文档的元规则。但注意：**"阶段"这一道闸的判定，现在由 t1.py 引擎负责（§1.1），不再由 EMA 快照负责。**

## 1. YIJUN 六阶段：定义与战略友好度

六阶段标签与战略意图源自你提供的 YIJUN 六阶段图（A–F）。**标签和"该阶段适合什么策略"这部分是稳定的战略常识，v1→v2 不变**。变的是"怎么判定当前属于哪一段"——见 §1.1。

| 段 | 名称 | 战略友好 | 判定依据（指向 §1.1 引擎） |
|---|---|---|---|
| **A** | 震荡均衡 | 均值回归最佳 | 波动率压缩（ATR 比率 < 1.1×均值）且无明确趋势结构 |
| **B** | 突破转换 | 突破策略最佳 | 已呈 HH/HL（或 LL/LH）结构 + 价格逼近近期极值（<0.3%） |
| **C** | 稳定趋势 | 趋势跟随最佳 | HH/HL 成立 + 斜率平缓（0 < slope < 0.0008） |
| **D** | 加速趋势 | 趋势+回调最佳 | HH/HL 成立 + 斜率陡（slope ≥ 0.0008）且上影未失控 |
| **E** | 冲顶/冲底失稳 | 减仓 / 禁开新顺势单 | 陡趋势 + 近 40 根上/下影线占比 > 0.45（衰竭） |
| **F** | 高波动修正 | 等突破确认后跟随 | 波动率放大（ATR 比率 > 1.2×均值）且无清晰趋势结构 |

**关键认知**：F 段不是"下跌中继"的俗称，而是被单列的一档——核心是 **"修正途中，先等趋势反转信号再跟随，禁止抄底摸顶"**。YIJUN 在 F 栏写"趋势确认后跟随"，是本意，不是套话。

> 注意：A–F 在 t1.py 里是**可检测的"当前状态"**，不是 YIJUN 图里按年推进的"生命周期时序"。交易要的是当前状态，所以代码把它当状态机处理——这是对的。

## 1.1 权威判定引擎（docs/t1.py 真相，禁 ML，纯规则）

以下逐字还原 `detect_stage_raw()` 的逻辑。**未来任何 `detect_cycle()` 实现都必须与此一致，否则视为偏离真值源。**

### 1.1.1 输入与四维指标

```
detect_stage_raw(opens, highs, lows, closes, lookback=120):
    atr_arr   = calc_atr(highs, lows, closes, period=14)   # np.convolve valid 模式
    守卫: if len(atr_arr) < 60: return "A 震荡均衡"        # 数据不足默认 A
    current_atr = atr_arr[-1]
    atr_ma     = mean(atr_arr[-60:])                       # 60 根 ATR 滑动均值

    # 分段高低点（step=20，重叠滑动）
    seg_highs, seg_lows = [], []
    for i in range(lookback, len(closes)):
        seg_highs.append(max(highs[i-20:i]))
        seg_lows.append(min(lows[i-20:i]))
    diff_h = diff(seg_highs); diff_l = diff(seg_lows)
    higher_high = mean(diff_h >= 0) >= 0.80     # 80% 分段呈上升
    higher_low  = mean(diff_l >= 0) >= 0.80
    lower_high  = mean(diff_h <= 0) >= 0.80
    lower_low   = mean(diff_l <= 0) >= 0.80

    recent_high = max(highs[-lookback:])
    recent_low  = min(lows[-lookback:])
    last_close  = closes[-1]
```

**四维指标说明**：
1. **波动率 regime** —— `current_atr / atr_ma` 比率。自适应不同周期量级，比死阈值 ATR% 鲁棒。
2. **趋势结构** —— 分段 HH/LL 同向占比 ≥ 80%。捕捉"高点低点是否系统性抬升/降低"。
3. **斜率陡度** —— `slope_total = (close[-1] - close[-lookback]) / lookback`，每根平均涨跌，分 C（缓）/ D（陡）。
4. **衰竭影线** —— 近 40 根上/下影线占比 `shadow_ratio`，> 0.45 判 E（冲顶/冲底失稳）。

### 1.1.2 决策树（忠实还原，顺序不可换）

```
① if current_atr < atr_ma * 1.1:
       return "A 震荡均衡｜均值回归优先"          # 波动率压缩优先判 A

② slope_total = (close[-1] - close[-lookback]) / lookback

   多头分支: if higher_high and higher_low:
       if |close - recent_high| / recent_high < 0.003:
           return "B 向上突破转换｜突破策略"        # 价格贴近期高 = 突破
       if 0 < slope_total < 0.0008:
           return "C 稳定上升趋势｜趋势跟随"
       elif slope_total >= 0.0008:
           shadow = mean((high[i]-close[i])/(high[i]-low[i]) for i in -40..0)  # 上影占比
           return "E 冲顶失稳｜减仓，禁止新开多单" if shadow > 0.45 else "D 加速上升｜回踩续趋势"

   空头分支: if lower_high and lower_low:
       if |close - recent_low| / recent_low < 0.003:
           return "B 向下突破转换｜突破策略"
       if -0.0008 < slope_total < 0:
           return "C 稳定下跌趋势｜顺势空"
       elif slope_total <= -0.0008:
           shadow = mean((close[i]-low[i])/(high[i]-low[i]) for i in -40..0)   # 下影占比
           return "E 冲底失稳｜减仓，禁止新开空单" if shadow > 0.45 else "D 加速下跌｜反弹续空"

③ if current_atr > atr_ma * 1.2:
       return "F 高波动修正｜等待突破确认，禁止猜顶抄底"

④ return "A 震荡均衡｜均值回归优先"              # 灰色带（1.1~1.2×）掉回 A
```

**关键顺序陷阱**：① 波动率检查写在趋势结构之前——低波动慢涨会被强判 A 而漏 C。这是 t1.py 的**既有行为**，落地时必须保留一致（如需改，先回测，见 §1.1.5）。

### 1.1.3 多周期层级合成（4H > 1H > 1m）

t1.py 的 `__main__` 用三周期分别跑 `detect_stage_raw`，再按**层级权重**合成交易推演：

| 周期 | 角色 | 权重 | 用途 |
|---|---|---|---|
| **4H** | 大格局 | 最高 | 定 regime（箱体/趋势/修正） |
| **1H** | 中周期 | 中 | 定入场触发（B 突破 / E 失稳 / F 修正） |
| **1m** | 精细点位 | 不判阶段 | 仅用于精确进出场价位 |

**合成推演规则（忠实还原）**：
```
if "A 震荡均衡" in 4H:  → 大级别箱体：均值回归优先；1H 趋势仅当小波段，禁重仓追
elif "C"/"D"     in 4H:  → 大级别趋势：顺势回调开仓；避开 E 阶段新开仓
elif "F"         in 4H:  → 高波动修正：不猜反转，等 B 突破信号

if "B" in 1H:  → ✅ 1H 突破转换，可按规则准备入场
if "F" in 1H:  → ⚠️ 1H 高波动修正，严禁抄底摸顶
if "E" in 1H:  → ⚠️ 1H 冲顶/冲底失稳，只减仓，禁新开顺势单
```

### 1.1.4 StageFilter 防抖锁（仅回测逐 K 循环用）

快照模式直接用 `detect_stage_raw` 的 raw 输出；**回测逐 K 循环**必须套 `StageFilter`：

```python
class StageFilter:
    def __init__(self, confirm_bar=3): ...   # 连续 3 根同阶段才切换 stable_stage
    def update(self, raw_stage):
        # 同 raw 累加 same_count；达到 confirm_bar 才更新 stable_stage
```

> 防抖目的：避免单根 K 异常导致阶段在回测里反复抖动（未来函数 / 过拟合来源之一）。**实盘/快照不要用防抖**，否则会延迟信号。

### 1.1.5 已知待复核项（非缺陷，待回测校准，当前保持与 t1.py 一致）

这些是我审计 t1.py 时标记的"可能可优化点"，**未改代码、未改本文判定逻辑**，仅列出供未来回测验证：

1. `slope_total` 阈值 `0.0008` 是 TF 不变量——4H 每根 0.0008 与 1m 每根 0.0008 真实涨幅差 240 倍。同一阈值跨周期含义不同，建议按 TF 小时数归一化。
2. **A 优先级高于 C/D**（见 §1.1.2 ①在趋势结构前）——低波动慢涨会漏 C。是否先判结构再判波动，待回测定性。
3. 灰色带 `1.1× ~ 1.2×` 波动率落此区间既非 A 也非 F，最终掉回 A，边界模糊。
4. 1m 仍跑 `detect_stage_raw` 但推演完全忽略——浪费一次 fapi 调用（若仅精细点位，1m 不应再算 stage）。
5. `shadow_ratio > 0.45` 为经验值，未回测验证；E 触发强依赖它。

## 2. 多空识别决策树（四道闸，作用于"阶段已定"之后）

阶段由 §1.1 引擎给出后，再用四道闸决定具体方向。**注意：阶段这道闸的来源变了（t1.py），但四道闸本身的逻辑不变。**

```
看到形态
  └─ ① 判阶段（A/B/C/D/E/F，来自 t1.py 引擎）
       ├─ C/D → 默认顺势做多
       ├─ E   → 减多 / 找空拐点
       ├─ A   → 等突破方向（双向）
       └─ F   → 进位置判定 ↓
            └─ ② 判位置（相对 EMA20，次级确认层）
                 ├─ 形态在 EMA20 上方 + 4h MACD>0 + 放量站上 → 反弹做多（严格右侧）
                 └─ 形态在 EMA20 下方 + 4h MACD<0 + 反弹缩量 → 顺趋势做空（高胜率）
                      └─ ③+④ 确认信号（通用，两边都要过）
                           ├─ 收线确认 + 下一根同向 + 量≥前均 → 真信号，方向成立
                           └─ 仅影线刺穿 + 缩量 + 下一根反向吞没 → 假信号（死猫跳），反做
```

**四道闸的权重**（哪道偏空就压倒其他）：
- 阶段背景（①，t1.py）> 位置（②，EMA20 次级）> 动能（MACD，②里）> 确认（③④）
- 即：**背景偏空时，任何看涨形态默认按"诱多反弹"处理，除非右侧确认翻多**。

> EMA20 位置在此是**次级确认层**，不是阶段判定依据。阶段判定一律走 §1.1 引擎。

## 3. 真反转 vs 死猫跳（F/A 段最坑的一对，长得像、差在四维度）

| 维度 | 真反转（可做多） | 死猫跳（继续做空） |
|---|---|---|
| RSI 行为 | 突破 50 并**守住**（不回落） | 弹至 45–50 **即掉头** |
| 均线位置 | **站上 4h EMA20** | **站不上** EMA20 |
| 量能 | 反转根**放量**（≥前 20 根均量） | 反弹**缩量**（无人跟） |
| 下一根 | **同向延续**，不回吐涨幅 | **反向吞没**，回吐涨幅 |

> 死猫跳 = 做空行情里的诱多反弹。识别它的唯一办法是"等下一根"——任何形态在收线瞬间都不能下结论，必须等确认。

## 7. 认知陷阱（人/策略在 A/E 段必踩的坑）

1. **形态=方向幻觉**：看到看涨吞没就做多，忽略它在箱体内上沿=诱多。
2. **EMA 快照过拟合（v1 教训）**：用 EMA/MACD/RSI 单快照套阶段，把"箱体反弹"误判"趋势修正"。**这是 v1→v2 重写的根因，详见 §11。**
3. **逆势抄底**：1H=E 失稳后 RSI 弹起就觉得"到底了"，结果是死猫跳起点。
4. **把"反弹"当"反转"**：RSI 弹到 45 就 rejoice，没等站上边界 + 放量 + 下一根确认。
5. **左侧重仓**：在"看起来便宜"的位置摊平，忘了箱体可以很宽、很磨。
6. **忽视流动性日历**：劳动节提前休市=振幅收敛但跳空风险↑，仓位没调。

## 11. 典型案例：09-08 实跑 4H=A / 1H=E 推翻 F 早期

> 这是 v1→v2 重写的直接动因，必须作为反面教材固化，防止未来 AI 重蹈 EMA 快照覆辙。

**背景**：v1（09-07）基于 `market_cache` 的 EMA/MACD/RSI 快照，判 XAU 为 **F 段早期**（"趋势后的修正"），默认方向做空/中性，并给出"反弹至 4424（4h EMA20）做空"的作战表。

**翻车**：09-08 09:56 用 `docs/t1.py` 直连 fapi 实跑，结果：
- **4H = A 震荡均衡**（ATR 比率 18.45/26.52 = 0.70 < 1.1，波动率压缩到 60 周期均值的 7 成；分段高低点未达 80% 同向）
- **1H = E 冲顶失稳**（HH/HL 成立 + 推至 4514 后近 40 根上影占比超 0.45）
- 推演：**大级别箱体 [4288, 4700]，均值回归优先；1H 失败上冲后只减仓禁追**。

**根因分析**：
1. v1 的 EMA/MACD/RSI 快照把"箱体内的反弹（价格暂破 4h EMA20）"误读成"趋势转弱后的修正 F"——**典型单快照过拟合**。
2. XAU 近几周实际是**宽幅箱体乱震**，不是干净的趋势-修正结构。t1.py 的"波动率比率 + 分段高低点结构"比 EMA 位置更能识别箱体。
3. v1 缺多周期层级：用 1d/4h/1h 的 EMA 混在一起套阈值，没有"4H 定 regime、1H 定 trigger"的分工。

**结论与纪律**：
- **阶段判定一律以 `docs/t1.py` 引擎为唯一真值源**，禁止任何 EMA/MACD/RSI 主观套阶段。
- 若需复核阶段，直接跑 `t1.py`（`python docs/t1.py`），不要翻缓存或目测均线。
- v1 的"4.1 多空作战表"中基于 EMA 的价位（4424/4377 等）**仅作参考价位，不再是阶段判定依据**。
